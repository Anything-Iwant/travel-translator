# 여행 대화 번역기 — 네이버 카페 링크용 간단 버전

## 이 버전은 어떻게 동작하나요?
이 버전은 정적 웹사이트입니다. GitHub Pages에 올리면 인터넷 주소가 만들어지고, 그 주소를 네이버 카페 게시글에 링크하면 스마트폰에서 바로 열 수 있습니다. 별도의 Python 서버나 API 키 설정이 필요하지 않습니다.

- 말하기: 브라우저 음성 인식 기능
- 번역: MyMemory 공개 번역 API
- 번역 읽기: 스마트폰 브라우저의 음성 합성 기능
- 상대방 대답: 상단의 ⇄ 버튼으로 언어를 바꾼 뒤 말하기

## 중요 제한
이것은 가장 쉽게 배포하기 위한 시제품입니다. 브라우저 음성 인식은 iPhone/Android 및 브라우저에 따라 지원 여부가 다르며, 인터넷 연결이 필요할 수 있습니다. MyMemory 공개 번역 API는 사용량·속도·품질을 보장하지 않습니다. API 키를 노출하지 않기 위해 브라우저에서 직접 호출하는 공개 서비스를 사용합니다. 개인정보, 비밀번호, 카드 정보 등 민감한 문장은 입력하지 마세요.

품질과 속도를 보장하는 서비스로 키우려면 나중에 백엔드 서버와 인증된 유료 음성·번역 API로 교체해야 합니다. API 키를 HTML/JavaScript에 넣으면 안 됩니다.

## GitHub Pages 배포 — 초보자용
1. GitHub 계정에 로그인하고 `New repository`를 누릅니다.
2. 저장소 이름을 `travel-translator`로 정하고 Public으로 만듭니다.
3. 압축을 푼 폴더에서 `index.html`, `style.css`, `app.js`, `README_KO.md` 파일을 저장소 최상위에 업로드합니다. `docs` 폴더는 필요 없습니다.
4. 저장소에서 **Settings → Pages**로 이동합니다.
5. **Build and deployment**의 Source를 `Deploy from a branch`로 설정합니다.
6. Branch는 `main`, 폴더는 `/(root)`를 선택하고 Save를 누릅니다.
7. 잠시 기다리면 `https://사용자이름.github.io/travel-translator/` 형태의 주소가 표시됩니다. 실제 주소는 GitHub Pages 화면에 표시된 것을 사용하세요.
8. 주소를 스마트폰에서 열어 마이크 권한을 허용하고 시험합니다.
9. 작동을 확인한 뒤 그 HTTPS 주소를 네이버 카페 게시글에 붙여 넣습니다.

## 파일 구성
- `index.html`: 화면 구조
- `style.css`: 스마트폰 화면 디자인
- `app.js`: 음성 인식, 번역 요청, 기록, 음성 읽기
- `README_KO.md`: 한국어 사용 설명서

## 테스트 방법
1. 최신 Chrome 또는 Safari에서 HTTPS 주소를 엽니다.
2. 출발 언어를 한국어, 도착 언어를 영어로 선택합니다.
3. 마이크 권한을 허용하고 말하기 버튼을 누릅니다.
4. 문장을 말한 후 인식이 끝날 때까지 기다립니다.
5. 번역 결과가 나오면 `번역 읽기`를 눌러 음성 출력을 확인합니다.
6. 상대방 차례에는 ⇄ 버튼을 눌러 언어 방향을 바꿉니다.

## 주의
GitHub Pages는 정적 파일 호스팅입니다. 이 앱의 코드에는 API 키가 없습니다. 공개 번역 서비스는 장애·제한이 있을 수 있습니다. 의료·법률·긴급·금융 관련 대화에서는 결과를 반드시 재확인하세요.
